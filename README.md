## 🌐 Free Deployment (GitHub Pages / Vercel / Netlify)

1. Push this folder to a GitHub repository:
   ```bash
   git init
   git add .
   git commit -m "Initial portfolio for Shashwat Bhatt"
   git branch -M main
   git remote add origin https://github.com/shashwatbhatt/portfolio.git
   git push -u origin main
   ```
2. Enable **GitHub Pages** under repository **Settings > Pages > Deploy from a branch (`main`)**.
3. Your portfolio is now live for college presentations, faculty evaluation, and internship applications!
